# Third-party notices

The academic site's layouts, styles, and navigation use the official [al-folio](https://github.com/alshedivat/al-folio) `al_folio_core` gem, pinned to 1.0.15. The upstream project is distributed under the MIT license; its notice is preserved in `licenses/al-folio.txt`.

The browser atlas reuses the existing Kang Lab React atlas code and depends on React, React Router, pdf-lib, and fflate. Exact dependency versions are recorded in `atlas/package-lock.json`. Their license notices remain distributed with their packages.

Software repository cards link to external projects. Each repository retains its own authorship and license, including the upstream projects explicitly linked on the resources page.

ORCID provides the public works and affiliation records. Crossref publisher metadata supplies author lists, matched by DOI. Source identifiers remain attached to the imported data and displayed publication links.

The atlas data snapshot retains source citations in its manifest. No new license is asserted over third-party datasets by this notice.

# External Resource Directory

Reviewed: 2026-09-30. Public display language: English.

## Legacy content audit

The previous React/Express site's MySQL resource tables were inspected read-only.
The eight approved records include seed/demo content, test titles, placeholder
URLs, generic search-engine destinations inconsistent with their descriptions,
and expert records without verifiable official profile links. None was copied
into the public directory as an established resource or collaborator. No database
records, approval flags or legacy pages were changed.

This is a newly curated directory, not a claim that the old database already
contained the links below. It does not imply affiliation, endorsement or
collaboration with the listed groups. No personal contact details are copied.
